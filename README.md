## 📖 Overview

This project is a four-wheel Bluetooth controlled robot car built using an Arduino UNO and the Adafruit Motor Shield V1. The robot is wirelessly controlled through a custom Android application using the HC-05 Bluetooth module.

The goal of this project was to learn embedded systems, wireless communication, and motor control while building a reliable mobile robot.

---

## ✨ Features

- 📱 Wireless Bluetooth control
- 🚗 Forward, backward, left and right, forward left and right, backward left and right movement
- 🛑 Instant stop control
- 📡 HC-05 Bluetooth communication
- ⚡ Powered by Arduino UNO
- 🤖 Four-wheel drive

## 🚀 Getting Started

### Requirements

- Arduino IDE
- Arduino UNO
- Adafruit Motor Shield V1
- HC-05 Bluetooth Module

### Installation

1. Clone this repository

```bash
git clone https://github.com/abhiramcore/Bluetooth-Car-V1
```

2. Open the Arduino sketch.

3. Connect the Arduino UNO.

4. Upload the code.

5. Pair your phone with the HC-05 Bluetooth module.

6. Open the Android application.

7. Start driving!
